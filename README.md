## 🛠️ Remote Dev & Homelab Architecture

> [!NOTE]
> Workflows are orchestrated remotely from a tablet setup via encrypted mesh networking.

```mermaid
flowchart LR
    subgraph Client["📱 Mobile Command"]
        Pad["Xiaomi Pad<br/>(Tailscale Client)"]
    end

    subgraph Network["🔐 Private Mesh"]
        TS["Tailscale Mesh VPN"]
    end

    subgraph Infra["🏠 Homelab Node"]
        CS["💻 code-server"]
        FB["📁 FileBrowser"]
        NX["📦 NEXUS Engine"]
        KR["🖥️ KRDP Remote"]
    end

    subgraph Deploy["☁️ Production"]
        PROD["🚀 Cloudflare / Vercel"]
    end

    Pad --> TS
    TS --> CS & FB & NX & KR
    CS -. Auto Deploy .-> PROD
```
